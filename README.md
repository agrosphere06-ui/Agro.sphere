# Agro-Sphere — Farmer Market Intelligence Platform

A comprehensive web platform empowering farmers with market intelligence, crop price tracking, collective selling, weather updates, smart scheduling, and direct transactions.

## Features
- **Market Dashboard**: Real-time mandi prices, trend indicators, and market updates.
- **Price Intelligence**: Multi-market price comparisons and predictive insights.
- **Product Availability & Listings**: Manage produce inventory and direct buyer connections.
- **Farmer Collective**: Group selling, bulk orders, and logistics sharing.
- **Smart Scheduling & Harvest Planner**: Optimize harvest and transport schedules based on market demand.
- **Transactions & Ledger**: Digital record of crop sales and receipts.
- **Multilingual Support**: Interactive localization interface.

## Tech Stack
- HTML5
- CSS3
- Modern JavaScript (ES6+)

## Quick Start
Open `index.html` in any modern web browser or serve with:
```bash
py -3.13 server.py
```
Then visit http://127.0.0.1:5000 or http://127.0.0.1:5000/login.
